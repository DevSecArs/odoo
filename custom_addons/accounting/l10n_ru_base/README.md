# Россия - Базовая локализация

**Базовый модуль с централизованными настройками российской локализации**

## Описание

Этот модуль предоставляет базовую функциональность для российской локализации и является **обязательной зависимостью** для всех других модулей российской локализации.

## Основные функции

### 🔧 Центральная панель настроек
- Единая точка управления всеми модулями российской локализации
- Возможность включения/выключения отдельных модулей
- Проверка корректности настроек

### 📋 Управляемые модули
- **Акты сверки взаиморасчетов** (l10n_ru_act_rev)
- **Управление договорами** (l10n_ru_contract)
- **УПД в формате XML** (l10n_ru_upd_xml)
- **Печатные формы документов** (l10n_ru_doc)
- **Доверенности** (l10n_ru_attorney)

### ⚙️ Базовые настройки
- Конфигурация для российских компаний
- Проверка заполнения обязательных реквизитов
- Валидация настроек локализации

## Установка

### Автоматическая установка
Модуль устанавливается автоматически при установке основного приложения **"Россия - Бухгалтерия"**.

### Ручная установка
1. Скопируйте папку `l10n_ru_base` в директорию `addons`
2. Перезапустите Odoo
3. **Приложения** → **Обновить список приложений**
4. Найдите "Россия - Базовые настройки"
5. Нажмите **"Установить"**

## Настройка

### Доступ к панели настроек
1. **Настройки** → **Общие настройки**
2. Найдите раздел **"Россия - Бухгалтерия"**
3. Включите/выключите необходимые модули

### Настройки модулей

#### ✅ Акты сверки
- **Назначение**: Создание актов сверки взаиморасчетов
- **Требования**: Настроенный модуль Бухгалтерия
- **Использование**: Контакты → Действия → Печать акт сверки

#### ✅ Договоры
- **Назначение**: Управление договорами с контрагентами
- **Требования**: Модули Продаж и Покупок
- **Использование**: Продажи/Покупки → Договоры

#### ✅ УПД XML
- **Назначение**: Экспорт УПД в формате XML 5.01
- **Требования**: Библиотека lxml, коды ОКЕИ
- **Использование**: Бухгалтерия → Печать → УПД XML

#### ✅ Печатные формы
- **Назначение**: Российские печатные формы документов
- **Требования**: Библиотека pytils
- **Использование**: Любые документы → Печать

#### ✅ Доверенности
- **Назначение**: Доверенности на получение ТМЦ
- **Требования**: Модули Покупок и HR
- **Использование**: Покупки → Доверенности

## Требования к настройке компании

Для корректной работы всех модулей необходимо настроить:

### Обязательные реквизиты
- **ИНН** - индивидуальный налоговый номер
- **КПП** - код причины постановки на учет
- **ОГРН/ОГРНИП** - основной государственный регистрационный номер
- **Юридический адрес** - полный адрес компании

### Дополнительные реквизиты
- **Название компании** (полное и сокращенное)
- **Банковские реквизиты** (БИК, расчетный счет)
- **Руководитель** (ФИО, должность)
- **Главный бухгалтер** (ФИО)
- **Контактные данные** (телефон, email)

## Проверка настроек

### Автоматическая проверка
Модуль автоматически проверяет:
- Соответствие страны компании (должна быть Россия)
- Наличие всех обязательных реквизитов
- Корректность формата ИНН, КПП, ОГРН

### Ручная проверка
1. **Настройки** → **Компании** → **Компании**
2. Убедитесь, что все поля заполнены корректно
3. Проверьте формат российских реквизитов

## Устранение неполадок

### Ошибка "Признак Российской компании не обнаружен"
**Причина**: Страна компании не установлена как "Россия"
**Решение**: 
1. **Настройки** → **Компании** → **Компании**
2. Во вкладке **"Общая информация"** установите **Страна**: Российская Федерация

### Модули не активируются
**Причина**: Отсутствуют зависимости или лицензия
**Решение**:
1. Проверьте установку всех зависимых модулей
2. Обратитесь в техподдержку для получения лицензии

### Ошибки при включении модулей
**Причина**: Неполная установка или конфликт модулей
**Решение**:
1. Перезапустите Odoo
2. Обновите список приложений
3. Переустановите проблемный модуль

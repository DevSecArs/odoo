Россия - Базовая локализация

Основное приложение российской локализации для Odoo 18

Описание: Базовый модуль с централизованными настройками российской локализации.

Центральная панель настроек

  • Единая точка управления всеми модулями российской локализации.
  • Возможность включения/выключения отдельных модулей.
  • Проверка корректности настроек.

Управляемые модули

  • Акты сверки взаиморасчетов (l10n_ru_act_rev)
  • Управление договорами (l10n_ru_contract)
  • Печатные формы документов (l10n_ru_doc)
  • Доверенности (l10n_ru_attorney)

Дополнительные модули

Устанавливаются отдельно через меню "Приложения":

  • УПД в формате XML (l10n_ru_upd_xml)

Использование

  1. Установите этот модуль как основное приложение "Россия - Базовая локализация".
  2. Все обязательные модули будут установлены автоматически.
  3. При необходимости установите дополнительные модули через меню "Приложения".

ВАЖНО:

  • Этот модуль должен использоваться как основное приложение "Россия - Базовая локализация".
  • Для работы некоторых модулей требуются дополнительные Python библиотеки.
  • Удаление данного модуля приведет к неработоспособности всех других модулей российской локализации.

Требования к настройке компании

Для корректной работы всех модулей необходимо настроить обязательные реквизиты:

  • ИНН - индивидуальный налоговый номер
  • КПП - код причины постановки на учет
  • ОГРН/ОГРНИП - основной государственный регистрационный номер
  • Юридический адрес - полный адрес компании

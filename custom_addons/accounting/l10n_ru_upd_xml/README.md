# Россия - УПД XML

**Модуль для создания УПД в формате XML (формат 5.01)**

## Описание

Модуль предоставляет возможность создания Универсальных передаточных документов (УПД) в формате XML в соответствии с российским законодательством (формат 5.01). Позволяет формировать электронные документы для передачи через операторов электронного документооборота (ЭДО).

## Основные функции

### 📊 Генерация УПД XML
- **Формат XML 5.01** - актуальная версия по требованиям ФНС
- **Автоматическое заполнение** всех обязательных реквизитов
- **Валидация данных** на соответствие формату
- **Экспорт в XML-файл** для передачи через ЭДО

### 🏢 Поддержка реквизитов
- **Полные реквизиты** продавца и покупателя
- **ИНН, КПП, ОГРН** всех участников
- **Банковские реквизиты** сторон
- **Адреса** юридические и фактические
- **Коды ОКПО, ОКВЭД** (при наличии)

### 📋 Товарные данные
- **Справочник ОКЕИ** для единиц измерения
- **Коды товаров** по ОКПД2, ТН ВЭД
- **НДС по ставкам** 0%, 10%, 20%, без НДС
- **Акцизы** (при необходимости)
- **Скидки и наценки**

### 🔧 Техническая интеграция
- **Интеграция с модулем Бухгалтерия**
- **Связь с счетами-фактурами**
- **Автоматический расчет** сумм и налогов
- **Поддержка валют** и курсов
- **JavaScript-компоненты** для веб-интерфейса

## Настройка

### Настройка компании
Заполните **все обязательные поля**:

#### Основные реквизиты
- ✅ **ИНН** - 10 или 12 цифр (обязательно)
- ✅ **КПП** - 9 цифр для юридических лиц
- ✅ **ОГРН/ОГРНИП** - 13 или 15 цифр
- ✅ **Полное наименование** организации
- ✅ **Сокращенное наименование**

#### Адресные данные
- ✅ **Юридический адрес** (полный, с индексом)
- ✅ **Фактический адрес** (если отличается)
- ✅ **Код региона** по КЛАДР/ФИАС
- ✅ **Телефон, факс, email**

#### Банковские реквизиты
- ✅ **БИК банка** - 9 цифр
- ✅ **Расчетный счет** - 20 цифр
- ✅ **Корреспондентский счет** банка
- ✅ **Наименование банка** (полное)

#### Руководители
- ✅ **Руководитель** (ФИО, должность)
- ✅ **Главный бухгалтер** (ФИО)
- ✅ **Основания полномочий** (устав, доверенность)

### Настройка контрагентов
Для каждого контрагента заполните:

#### Реквизиты организации
- ✅ **ИНН** (обязательно)
- ✅ **КПП** для юридических лиц
- ✅ **ОГРН/ОГРНИП**
- ✅ **Полное наименование**
- ✅ **Юридический адрес**

#### Банковские данные
- ✅ **БИК банка контрагента**
- ✅ **Расчетный счет**
- ✅ **Наименование банка**

### Настройка единиц измерения
Очень важно настроить коды ОКЕИ:

1. **Склад** → **Конфигурация** → **Единицы измерения**
2. Для каждой единицы измерения укажите **Код ОКЕИ**:
   - **шт.** - 796
   - **кг** - 166
   - **л** - 112
   - **м** - 006
   - **м²** - 055
   - **м³** - 113
   - **т** - 168
   - **упак** - 778

### Настройка товаров
Для корректного УПД настройте:
- **Точные наименования** товаров/услуг
- **Единицы измерения** с кодами ОКЕИ
- **Коды товаров** ОКПД2 или ТН ВЭД (при экспорте)
- **Ставки НДС** для каждого товара

## Использование

### Создание УПД из счета

#### Шаг 1: Подготовка счета
1. Откройте **Бухгалтерия** → **Клиенты** → **Счета**
2. Выберите нужный счет или создайте новый
3. Убедитесь, что счет **проведен** (статус "Разнесен")
4. Проверьте корректность всех данных:
   - Контрагент с заполненными реквизитами
   - Товары с единицами измерения
   - Правильные суммы и НДС

#### Шаг 2: Создание УПД XML
1. В открытом счете нажмите **"Печать"**
2. Выберите **"УПД XML"** из списка отчетов
3. Система откроет форму генерации УПД

#### Шаг 3: Проверка данных
Проверьте автоматически заполненные поля:
- **Продавец**: ваша компания (реквизиты должны быть полными)
- **Покупатель**: контрагент (проверьте ИНН, КПП, адрес)
- **Товары**: наименования, количества, цены, НДС
- **Суммы**: итоговые суммы без НДС, НДС, всего

#### Шаг 4: Генерация XML
1. Нажмите **"Создать XML"**
2. Система выполнит валидацию данных
3. При успешной проверке будет создан XML-файл
4. **Скачайте файл** на компьютер

### Создание УПД из счета-фактуры

#### Аналогично счету
1. **Бухгалтерия** → **Поставщики** → **Счета**
2. Выберите входящий счет-фактуру
3. **"Печать"** → **"УПД XML"**
4. Проверьте и создайте XML

### Работа с созданными XML

#### Проверка файла
- Откройте XML в текстовом редакторе
- Проверьте корректность всех данных
- Убедитесь в отсутствии ошибок кодировки

#### Передача через ЭДО
1. Зайдите в систему вашего оператора ЭДО
2. Загрузите созданный XML-файл
3. Отправьте контрагенту
4. Дождитесь подтверждения получения

## Валидация и ошибки

### Частые ошибки валидации

#### "Не заполнен ИНН продавца"
**Решение**: Заполните ИНН в настройках компании

#### "Не заполнен адрес покупателя"
**Решение**: Дополните адрес в карточке контрагента

#### "Неизвестный код ОКЕИ"
**Решение**: Укажите правильный код ОКЕИ для единицы измерения

#### "Некорректная сумма НДС"
**Решение**: Проверьте настройки налогов и пересчитайте счет

### Проверка XML на корректность
1. Используйте онлайн-валидаторы XML
2. Проверьте файл в системе ЭДО
3. Сверьте с требованиями ФНС

## Форматы и стандарты

### Формат 5.01
- **Актуальная версия** по требованиям ФНС России
- **Совместимость** с основными системами ЭДО
- **Поддержка всех реквизитов** УПД
- **Соответствие** Приказу ФНС России

### Поддерживаемые операции
- **Отгрузка товаров** (основная функция УПД)
- **Оказание услуг**
- **Выполнение работ**
- **Передача имущественных прав**
- **Корректировочные УПД** (исправления)

### Типы документов
- **УПД** (универсальный передаточный документ)
- **УПДИ** (исправленный УПД)
- **УПДК** (корректировочный УПД)

## Интеграция с ЭДО

### Поддерживаемые операторы
Созданные XML-файлы совместимы с:
- **СКБ Контур**
- **Такс Лайн**
- **СБИС**
- **1С-ЭДО**
- **Калуга Астрал**
- Другие операторы, поддерживающие формат 5.01

## Устранение неполадок

### XML не создается
**Причина**: Ошибки валидации данных
**Решение**: Проверьте все обязательные поля, коды ОКЕИ

### Неправильные суммы в XML
**Причина**: Некорректные настройки налогов
**Решение**: Пересчитайте НДС в счете, проверьте ставки

### Ошибка "неизвестный тег"
**Причина**: Несовместимость версий формата
**Решение**: Обновите модуль до актуальной версии

### Проблемы с кодировкой
**Причина**: Некорректные символы в данных
**Решение**: Проверьте названия товаров, адреса на спецсимволы

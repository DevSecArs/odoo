# Россия - Договоры

**Модуль для создания и управления договорами с контрагентами**

## Описание

Модуль предоставляет функционал для создания, управления и печати договоров с контрагентами в соответствии с российским законодательством. Поддерживает автоматическое заполнение реквизитов, морфологическую обработку русских имен и интеграцию с модулями продаж и покупок.

## Основные функции

### 📝 Создание договоров
- **Договоры с клиентами** - для продаж товаров и услуг
- **Договоры с поставщиками** - для закупок и поставок
- **Автоматическая нумерация** договоров
- **Контроль сроков** действия договоров

### 🏢 Управление реквизитами
- **Автоматическое заполнение** данных компании
- **Реквизиты контрагентов** (ИНН, КПП, ОГРН)
- **Банковские реквизиты** сторон
- **Юридические адреса** и контакты

### 📄 Российское оформление
- **Стандартные шаблоны** договоров
- **Соответствие ГК РФ** и российской практике
- **Печать в формате PDF** с правильным оформлением
- **Морфологическая обработка** ФИО руководителей

### 🔗 Интеграция
- **Связь с заказами** на продажу и покупку
- **Автоматическое создание** из заказов
- **Привязка к счетам** и накладным
- **История изменений** договоров

## Установка

### Требования

- Модули **Продажи** и **Покупки**

```bash
pip install pymorphy2
```

### Активация модуля
1. **Настройки** → **Общие настройки**
2. Найдите раздел **"Россия - Бухгалтерия"**

## Настройка

### Настройка компании
Заполните все обязательные поля:
- ✅ **ИНН** - индивидуальный налоговый номер
- ✅ **КПП** - код причины постановки на учет
- ✅ **ОГРН/ОГРНИП** - регистрационный номер
- ✅ **Полное название** компании
- ✅ **Сокращенное название**
- ✅ **Юридический адрес** (индекс, регион, город, улица, дом)
- ✅ **Руководитель** (ФИО, должность)
- ✅ **Основание полномочий** руководителя (устав, доверенность)
- ✅ **Банковские реквизиты** (БИК, расчетный счет, банк)

### Настройка контрагентов
Для каждого контрагента укажите:
- ✅ **ИНН** - обязательно
- ✅ **КПП** (для юридических лиц)
- ✅ **ОГРН/ОГРНИП**
- ✅ **Полное название**
- ✅ **Юридический адрес**
- ✅ **Руководитель** (ФИО, должность)
- ✅ **Основание полномочий** руководителя
- ✅ **Банковские реквизиты**

### Настройка сотрудников
В модуле **Сотрудники** укажите:
- **ФИО** сотрудников (для корректного склонения)
- **Должности** руководителей
- **Полномочия** (на основании чего действует)

## Использование

### Создание договора с клиентом

#### Из меню Продажи
1. **Продажи** → **Договоры** → **Договоры клиентов**
2. Нажмите **"Создать"**
3. Заполните основные данные:
   - **Контрагент**: выберите клиента
   - **Номер договора**: введите или оставьте автоматический
   - **Дата заключения**: дата подписания
   - **Дата начала действия**: когда договор вступает в силу
   - **Дата окончания**: срок действия (опционально)
   - **Предмет договора**: что продаете/покупаете

#### Из заказа на продажу
1. Откройте **Заказ на продажу**
2. Нажмите **"Создать договор"**
3. Система автоматически заполнит данные из заказа
4. Дополните недостающую информацию

### Создание договора с поставщиком

#### Из меню Покупки
1. **Покупки** → **Договоры** → **Договоры поставщиков**
2. Нажмите **"Создать"**
3. Заполните аналогично договору с клиентом

#### Из заказа на покупку
1. Откройте **Заказ на покупку**
2. Нажмите **"Создать договор"**
3. Проверьте автоматически заполненные данные

### Заполнение дополнительных данных

#### Условия оплаты
- **Сумма договора**: общая стоимость
- **Валюта**: рубли, доллары, евро
- **Условия оплаты**: предоплата, отсрочка, факт поставки
- **Реквизиты для оплаты**: банковские данные

#### Условия поставки
- **Место поставки**: адрес доставки
- **Сроки поставки**: когда должны поставить
- **Условия приемки**: как принимается товар
- **Ответственность сторон**: штрафы, пени

#### Подписанты
- **От нашей компании**: руководитель или уполномоченное лицо
- **От контрагента**: руководитель или представитель
- **Основание полномочий**: устав, доверенность

### Печать договора

1. Откройте созданный договор
2. Нажмите **"Печать"** → **"Договор"**
3. Система сформирует PDF с:
   - Правильным оформлением шапки
   - Склоненными ФИО руководителей
   - Всеми реквизитами сторон
   - Предметом и условиями договора
   - Местами для подписей и печатей

## Автоматизация

### Создание из заказов
- При подтверждении заказа можно автоматически создать договор
- Данные заказа переносятся в договор
- Номенклатура и суммы заполняются автоматически

### Связь с документами
- Договоры автоматически связываются с заказами
- При создании счета указывается номер договора
- В накладных отображается ссылка на договор

### Уведомления об истечении
- Система может уведомлять об истекающих договорах
- Автоматическое продление договоров (настраивается)
- Блокировка операций по истекшим договорам

## Морфологическая обработка

### Возможности pymorphy2
- **Склонение ФИО** руководителей по падежам
- **Согласование** должностей с ФИО
- **Правильные формы** в зависимости от контекста
- **Поддержка** мужских и женских ФИО

### Примеры склонения
- **Иванов Иван Иванович** → "Иванова Ивана Ивановича"
- **Генеральный директор** → "генерального директора"
- **Действующего на основании** устава/доверенности

## Устранение неполадок

### Ошибки склонения ФИО
**Причина**: Не установлена библиотека pymorphy2
**Решение**: 
```bash
pip install pymorphy2
```

### Пустые поля в договоре
**Причина**: Незаполненные реквизиты компании или контрагента
**Решение**: Заполните все обязательные поля в карточках

### Некорректные банковские реквизиты
**Причина**: Неправильный формат БИК или расчетного счета
**Решение**: Проверьте формат реквизитов (БИК - 9 цифр, р/с - 20 цифр)

# Россия - Акты сверки

**Модуль для создания и печати актов сверки взаиморасчетов**

## Описание

Модуль предоставляет возможность создания и печати актов сверки взаиморасчетов с контрагентами в соответствии с российским законодательством. Позволяет легко отслеживать дебеторскую и кредиторскую задолженность по любому партнеру.

## Основные функции

### 📊 Создание актов сверки
- Генерация актов сверки по любому контрагенту
- Отображение всех операций за выбранный период
- Расчет входящих и исходящих сальдо
- Детализация по каждой проводке

### 🎯 Гибкая фильтрация
- **По периоду**: выбор даты начала и окончания
- **По компании**: сверка для конкретной компании
- **По типу проводок**: 
  - Только проведенные проводки
  - Все проводки (включая черновики)

### 📄 Форматы вывода
- **PDF-документ** с российским оформлением
- **Портальный доступ** для клиентов
- **Печать** прямо из браузера

### 🔍 Детальная информация
- Дата и номер каждой операции
- Дебет и кредит по каждой проводке
- Нарастающий итог по периоду
- Итоговые суммы задолженностей

## Установка

### Требования
- Установленное основное приложение **"Россия - Бухгалтерия"**
- Настроенный модуль **Выставление счетов** (обязательно)
- Модуль **Контакты**

### Активация модуля
1. **Настройки** → **Общие настройки**
2. Найдите раздел **"Россия - Бухгалтерия"**
3. Включите **"Акты сверки"**
4. Нажмите **"Сохранить"**

## Настройка

### Настройка компании
Убедитесь, что у компании заполнены:
- ✅ **ИНН** - обязательно
- ✅ **КПП** - обязательно  
- ✅ **ОГРН/ОГРНИП** - обязательно
- ✅ **Название** (полное и сокращенное)
- ✅ **Юридический адрес**
- ✅ **Руководитель** (ФИО, должность)
- ✅ **Главный бухгалтер** (ФИО)

### Настройка контрагентов
Для каждого контрагента заполните:
- ✅ **ИНН** - обязательно
- ✅ **КПП** (для юридических лиц)
- ✅ **Название** компании
- ✅ **Адрес**

### Настройка проводок
- Убедитесь, что ведется учет в модуле **Выставление счетов**
- Проводки должны быть правильно разнесены по партнерам
- Для получения актуальных данных проводки должны быть проведены

## Использование

### Создание акта сверки

#### Способ 1: Через карточку контрагента
1. **Контакты** → выберите нужного партнера
2. Нажмите **"Действия"** → **"Печать акт сверки"**
3. В открывшемся мастере заполните:
   - **Компания**: выберите компанию для сверки
   - **Дата начала**: начало периода сверки
   - **Дата окончания**: конец периода сверки
   - **Цель**: 
     - *Проведенные проводки* - только подтвержденные операции
     - *Все проводки* - включая черновики
4. Нажмите **"Печать"**

#### Способ 2: Через модуль Выставление счетов
1. **Выставление счетов** → **Отчеты** → **Отчеты по партнерам** → **Акты сверки**
2. Выберите партнера и параметры
3. Сформируйте отчет

### Работа с готовым актом

#### Содержание акта сверки
- **Заголовок**: название документа, период, участники
- **Реквизиты сторон**: полные данные компании и контрагента
- **Таблица операций**: 
  - Дата операции
  - Номер документа
  - Описание операции  
  - Дебет (наша задолженность)
  - Кредит (задолженность контрагента)
  - Сальдо нарастающим итогом
- **Итоги**: входящее сальдо, обороты, исходящее сальдо
- **Подписи**: места для подписей сторон

#### Действия с актом
- **Печать**: распечатать на принтере
- **Сохранение**: сохранить PDF-файл
- **Отправка**: переслать контрагенту по email
- **Портал**: предоставить доступ через клиентский портал

## Портальный доступ

### Настройка доступа для клиентов
1. У контрагента должен быть настроен **Пользователь портала**
2. **Контакты** → выберите партнера → вкладка **"Внутренняя информация"**
3. Создайте пользователя портала или свяжите с существующим

### Доступ клиента к актам сверки
1. Клиент входит в портал через свой аккаунт
2. На главной странице портала доступна кнопка **"Печатать акт сверки"**
3. Система автоматически создает акт сверки для текущего пользователя
4. Клиент может скачать PDF-версию акта сверки

### Веб-роуты для актов сверки
- **`/my/act_revise/a`** - Быстрое создание акта сверки для текущего пользователя
- **`/my/act_revise_contact/<act>`** - Создание акта с параметрами (даты, тип проводок)

### Функциональность портала
- **Автоматическое определение** контрагента по текущему пользователю
- **Быстрый доступ** к актам сверки без входа в основной интерфейс Odoo
- **PDF-генерация** прямо в браузере
- **Настраиваемые параметры** через URL-параметры

## Примеры использования

### Ежемесячная сверка с поставщиками
1. В конце месяца откройте карточки основных поставщиков
2. Создайте акты сверки за прошедший месяц
3. Отправьте акты поставщикам для подтверждения
4. Сверьте данные и урегулируйте расхождения

### Квартальная сверка с клиентами
1. В конце квартала выберите крупных клиентов
2. Сформируйте акты сверки за квартал
3. Предоставьте доступ через портал или отправьте по email
4. Получите подписанные акты обратно

### Годовая сверка
1. Перед сдачей годовой отчетности
2. Создайте акты сверки за весь год
3. Убедитесь в отсутствии расхождений
4. Подготовьте документы для аудита

## Устранение неполадок

### Акт сверки пустой
**Причина**: Нет проводок с выбранным партнером
**Решение**: 
- Проверьте, что операции правильно разнесены по партнерам
- Убедитесь, что выбран правильный период
- Проверьте, что проводки проведены

### Неправильные суммы
**Причина**: Некорректные настройки счетов или проводок
**Решение**:
- Проверьте настройки плана счетов
- Убедитесь в правильности проводок
- Пересчитайте сальдо в модуле Выставление счетов

### Ошибка при печати
**Причина**: Незаполненные реквизиты компании или партнера
**Решение**:
- Заполните все обязательные поля в карточке компании
- Проверьте реквизиты контрагента
- Убедитесь, что ИНН заполнен у обеих сторон

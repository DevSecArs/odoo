# Россия - Бухгалтерские документы

**Модуль российской локализации для печатных форм документов в Odoo 18**

## Описание

Этот модуль предоставляет функционал для создания печатных форм документов в соответствии с российским законодательством. Он является частью комплексной российской локализации и зависит от базового модуля l10n_ru_base.

## Основные функции

### 📋 Печатные формы документов
- Товарная накладная (ТОРГ-12)
- Счета на оплату
- Счета-фактуры
- Акты выполненных работ
- Универсальные передаточные документы (УПД)
- УПД без печатей

### 🏢 Российская компания
- Поля ИНН, КПП, ОКПО для компаний и контрагентов
- Назначение руководителя и главного бухгалтера
- Добавление факсимиле и печатей
- Настройки печати документов

## Установка

### Требования
- Odoo 18.0+
- Python 3.8+
- PostgreSQL 12+
- Базовый модуль l10n_ru_base

### Python зависимости
```bash
pip install pytils
```

### Процесс установки
1. Убедитесь, что установлен модуль l10n_ru_base
2. Скопируйте папку `l10n_ru_doc` в директорию `addons` вашего Odoo
3. Перезапустите Odoo сервер
4. Обновите список приложений: Приложения → Обновить список приложений
5. Найдите "Россия - Бухгалтерские документы" в списке модулей
6. Нажмите "Установить"

## Настройка

### 1. Настройка компании
1. **Настройки** → **Компании** → **Компании**
2. Заполните российские реквизиты:
   - ИНН (обязательно)
   - КПП (обязательно)
   - ОКПО
3. Назначьте руководителя и главного бухгалтера
4. Добавьте печать компании (опционально)
5. Настройте параметры печати (факсимиле, печать, где печатать)

### 2. Настройка контрагентов
1. **Контакты** → выберите контрагента
2. Заполните вкладку с российскими реквизитами:
   - ИНН
   - КПП (для юридических лиц)
   - ОКПО

## Использование

### Печать российских документов
1. Откройте нужный документ (счет, заказ продаж)
2. Нажмите **"Печать"** или **"Действия"** → **"Печать"**
3. Выберите нужную форму документа:
   - Счет по форме 1С
   - Счет-фактура
   - Товарная накладная (ТОРГ-12)
   - Акт выполненных работ
   - Универсальный передаточный документ (УПД)
   - УПД без печатей
4. Документ будет сформирован в соответствии с российскими требованиями

Россия - Бухгалтерские документы

Модуль российской локализации для печатных форм документов в Odoo 18

Описание: Этот модуль предоставляет функционал для создания печатных форм документов в соответствии с российским законодательством. Он является частью комплексной российской локализации и зависит от базового модуля l10n_ru_base.

Печатные формы документов

  • Товарная накладная (ТОРГ-12)
  • Счета на оплату
  • Счета-фактуры
  • Акты выполненных работ
  • Универсальные передаточные документы (УПД)
  • УПД без печатей

Российская компания

  • Поля ИНН, КПП, ОКПО для компаний и контрагентов
  • Назначение руководителя и главного бухгалтера
  • Добавление факсимиле и печатей
  • Настройки печати документов

Поддерживаемые документы

  • Счет по форме 1С - для заказов продаж
  • Счет-фактура - для счетов
  • Товарная накладная (ТОРГ-12) - для счетов
  • Акт выполненных работ - для счетов
  • Универсальный передаточный документ (УПД) - для счетов
  • УПД без печатей - для счетов

Как пользоваться модулем

После установки модуля вы можете использовать российские печатные формы документов в различных разделах системы:

Продажи

Откройте заказ продажи или счет и выберите в меню "Действия" → "Печать" для создания документа по форме 1С.

Бухгалтерия

В разделе Бухгалтерия откройте счет или счет-фактуру и выберите в меню "Действия" → "Печать" нужный документ:

  • Товарная накладная (ТОРГ-12)
  • Счет-фактура
  • Акт выполненных работ
  • Универсальный передаточный документ (УПД)
  • УПД без печатей
Настройка компании

Перейдите в Настройки → Компании → Компании для настройки российских реквизитов:

  • Заполните ИНН, КПП, ОКПО
  • Назначьте руководителя и главного бухгалтера
  • Добавьте печать компании (опционально)
  • Настройте параметры печати документов
Настройка контрагентов

В разделе Контакты заполните российские реквизиты контрагентов:

  • ИНН
  • КПП (для юридических лиц)
  • ОКПО

ВАЖНО:

  • Для работы требуется установка дополнительных Python библиотек (pytils).
  • Модуль должен использоваться вместе с основным приложением "Россия - Базовая локализация".
